# Dr.Anmar vessel and vascular clip

This family contains the repository-local vessel, explicit tetrahedral layer,
and rigid vascular clip used by the hemostasis rooms. The authoritative
physics contract is
`physics_next/vessels/dr-anmar-hemostasis-v1.json`; the JSON files beside the
USD entrypoints record generated validation evidence.

These are simulation and research assets. Pressure-tight occlusion, plastic
clip forming, bleeding, rupture, and clinical validity require separate
qualification and are not implied by a successful catalog check.
