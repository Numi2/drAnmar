# ORBIT-Surgical needle with Dr.Anmar suture

These compositions retain the curved needle geometry and collision layer from
the ORBIT-Surgical baseline and attach the Dr.Anmar 4-0 suture. Provider
attribution and the imported-baseline notice remain in the repository
`NOTICE.md`.

The standard entrypoint selects the PhysX-compatible suture. The interactive
entrypoint selects the retained interactive strand representation. Neither is
clinical evidence.
