# Dr.Anmar layered suture needle

`DrAnmarNeedle.usda` composes geometry, materials, neutral physics, and the
PhysX payload around the factory-swaged Dr.Anmar 4-0 suture.
`DrAnmarNeedleOnly.usda` is the needle-only entrypoint, while
`DrAnmarNeedle_interactive.usda` selects the retained interactive layer.

The family is portable OpenUSD with repository-relative dependencies. A valid
catalog and layer closure do not replace native Isaac/PhysX convergence,
metrology, swage-pullout, or clinical qualification.
