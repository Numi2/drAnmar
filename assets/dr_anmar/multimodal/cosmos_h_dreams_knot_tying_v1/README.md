# Cosmos-H-Dreams source audit and Dr.Anmar multimodal contract

This dependency-complete data asset records the static audit of the
Cosmos-H-Dreams example bundle and adds a safe Dr.Anmar-native action fixture.
The upstream video, image, trajectory, statistics, model checkpoint, and text
embedding are intentionally not copied into this repository. Their immutable
source revisions, byte sizes, and SHA-256 values are recorded in
`asset_bundle.json`.

The included dual-PSM stream is generated by
`scripts/generate_dranmar_multimodal_fixture.py`. It exercises dimension,
timestamp, interpolation, bound, discrete-gripper, neutral-endpoint, and
stale-input behavior. It is not a recorded procedure, is not paired to the
upstream video, is not eligible as a training reference, and has no native,
real-world, or clinical evidence.

Generated frames are observations only. They cannot author physics, robot
commands, patient effects, or success labels. Use OpenUSD/PhysX state and
timestamped native action/state streams for those functions.
