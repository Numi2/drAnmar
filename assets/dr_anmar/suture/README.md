# Dr.Anmar braided 4-0 suture

The composed suture separates geometry, material, neutral physics, and PhysX
layers so a room can select the appropriate backend without contaminating the
portable base. The active knotting backend and GPU evidence are documented in
`docs/DR_ANMAR_WARP_SUTURE.md` and
`physics_next/benchmarks/dr-anmar-warp-suture-native-simulator-evidence.json`.

Catalog integrity proves only that the layers and dependencies are complete.
It does not claim measured tensile, knot-security, tissue-response, or clinical
performance.
