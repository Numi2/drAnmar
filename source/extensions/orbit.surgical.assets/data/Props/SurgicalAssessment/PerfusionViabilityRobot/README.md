# DrAnmar Multimodal Perfusion and Tissue-Viability Robot

Research-only Franka hand-replacement for registered RGB, NIR/ICG, laser-speckle, thermal, Doppler, ultrasound, depth, and surface-oxygenation assessment.

## Catalog path

`Props/SurgicalAssessment/PerfusionViabilityRobot`

## Primary contract

One vascular-flow and tracer state drives all modality outputs, confidence, disagreement, cause classification, and closed-loop rescan tasks.

This package is not clinically validated and is not approved for patient care.
