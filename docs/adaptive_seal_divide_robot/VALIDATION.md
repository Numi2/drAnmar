# Capability and evidence boundaries

The reviewed source binds each seal zone to exact contact, sensor, cohesive,
vessel, seal-band, attachment, blade, guard, bridge, alignment, raw-record,
topology, step, and physics-time identities. Contact vectors are serialized in
registered source-to-target orientation. Caller-authored seal maturity,
residual gap, stump flow, division, damage, and success scalars are not
accepted.

This pass was source review and editing only. No generator, validator, test,
build, simulator, or native runtime was executed. The repository does not
implement the native scene-evidence provider, so current simulator task
completion and physical behavior are unverified. Existing generated hashes and
manifests are stale until a separately authorized qualification run.

The obsolete runtime diagnostic and unit tests targeted removed caller-driven
energy, force, band-maturity, leak, and division APIs and were deleted rather
than retained as false assurance.

No repository evidence qualifies electrosurgical transport, tissue fusion,
sealed-stump burst strength, continuous division, injury extent, physical
calibration, clinical performance, or patient-care use.
