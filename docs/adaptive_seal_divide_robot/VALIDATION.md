# Capability and evidence boundaries

The Adaptive Seal-and-Divide Robot is an available Dr.Anmar
simulation-training workcell with centering, compression, sealing, guarded
division, task state, observations, actions, and evaluation signals.

Repository verification covers deterministic assets, dependency closure,
controller invariants, fail-closed attachment overlap, blade interlocks, and
source integrity. The optional Isaac script produces native-simulator evidence
only.

The current surface-shell vessel does not resolve calibrated through-thickness
compression. Measured generalized jaw effort below the authored force envelope
must keep the blade interlock closed; the threshold must not be lowered and a
synthetic force must not be injected to obtain a pass.

Seal efficacy, thermal fusion, burst pressure, division quality, physical
calibration, clinical performance, and patient-use evidence remain unestablished pending
a calibrated volumetric vessel/material and instrumented bench data.
