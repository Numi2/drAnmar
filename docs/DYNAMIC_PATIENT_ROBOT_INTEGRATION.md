# Robot integration

DrAnmar robots may command bounded motion, but a command or structured event is
not patient-effect evidence. The former event registry that accepted authored
seal quality, division, patency, closure, injury, perfusion, or infusion values
is disabled and is not attached to runtime patients.

Patient effects must originate in the owning mechanics subsystem and carry exact
post-physics source, target, contact/attachment, raw-record, topology, step,
time, and adapter identity. The patient runs without robot modules, but it does
not accept equivalent caller-authored outcome events. Workcells without a native
provider must abstain from changing patient outcome state.
