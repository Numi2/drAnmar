# Retired surface-FEM thread experiment

This folder preserves the superseded single-surface-deformable thread author
and validator for reproducibility. It is not a selectable puncture/pullout
runtime asset.

The experiment used a flat FEM ribbon as a suture. Although it remained
attached and could complete the analytical task receipt, its broad collision
surface transferred excessive normal forces into the tissue and produced
non-physical deformation in rendered puncture runs.

The puncture/pullout task now uses the white native DrAnmar 4-0 route derived
from the pinned SoftMimicGen volume-deformable strand instead. Results here are
simulator-engineering history only.
